**Sizzle Rush** — an original top-down cooking game for the desktop browser. Orders arrive on the board with patience bars; you grab ingredients from the fridge wall, chop on boards, cook patties, fish and rice on stoves, stack plates at the plate station, and serve matching dishes at the green Serve window before patience runs out. Combos raise your payout, missed orders cost hearts.

## Run it

```sh
node serve.ts        # then open http://localhost:8080
```
